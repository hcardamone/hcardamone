## What sets me apart: AI-assisted software engineering for SAP

I architected and built from scratch a **proprietary MCP Server in .NET 8** that connects AI agents (Claude, Cursor, Devin) to SAP:

- **From ECC 6.0 to S/4HANA Cloud (Basis 7.00+)** — Public MCP servers for SAP require ADT REST (Basis 740+); this one also covers the legacy systems many companies still run.
- **Multi-channel routing** — Automatic switching between RFC (SAP NCo), ADT REST and WebGUI (Playwright) to read any ABAP repository object (classes, FMs, DDIC) and run impact analysis (where-used, transports) in real time.
- **Security and performance** — Read-only by design: write operations become `.md` playbooks (Suggestion Mode) for the developer to execute. Cache isolated per SID/user.
- **Team impact** — A central repository of skills and playbooks that guide the AI through code analysis, documentation and test scripts, speeding up adoption by senior developers and shortening delivery cycles.
